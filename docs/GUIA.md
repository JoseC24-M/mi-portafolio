# Laboratorio 02: Ramas, Merge y Resolucion de Conflictos

Este proyecto es una pagina web minima desarrollada para practicar el uso de ramas, merge y resolucion de conflictos con Git.

## Tecnologias utilizadas

- Git
- HTML
- CSS
- GitHub

## Descripcion del proyecto

El proyecto consiste en una pagina web sencilla creada para practicar el trabajo con ramas en Git. Se trabajo con una rama principal y varias ramas para agregar funcionalidades y realizar cambios de estilos.

### Estructura del proyecto

El proyecto esta compuesto principalmente por los archivos `index.html` y `estilos.css`.

## Uso del proyecto

1. Descargar o clonar el repositorio desde GitHub.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir el archivo `index.html` en un navegador.

## Tareas realizadas

- [x] Crear ramas en Git
- [x] Realizar merge
- [x] Resolver un conflicto
- [x] Crear y publicar la etiqueta v1.0

## Archivos principales

| Archivo       | Descripcion                             |
| ------------- | --------------------------------------- |
| `index.html`  | Contiene la estructura de la pagina web |
| `estilos.css` | Contiene los estilos de la pagina       |
| `README.md`   | Documenta el proyecto                   |

## Comandos utilizados

Para revisar el estado del proyecto se utiliza `git status`.

```bash
git log --oneline --graph --all
git merge color-azul
git tag -a v1.0 -m "Version estable del laboratorio 02"
```
